Шаг 1. Открыть настройки внешнего инструмента
В верхнем меню IDE выберите:
Run → External Tools → External Tools Configurations...

Шаг 2. Создать новую конфигурацию
В левой части окна выберите Program.
Нажмите на иконку "New launch configuration" (белый листик с плюсиком). Появится новая запись.
Дайте ей имя, например: Показать секции ELF

Шаг 3. Заполнить поля (самое важное)
В правой части окна, на вкладке Main, заполните:

Location (путь к objdump):
Нажмите кнопку Variables..., найдите в списке переменную gnu_tools_for_stm32_compiler_path и выберите её.
Затем в поле Location допишите вручную:

Для Windows: /arm-none-eabi-objdump.exe

Для Linux/Mac: /arm-none-eabi-objdump

В итоге должно получиться так (пример для Windows):
${gnu_tools_for_stm32_compiler_path}/arm-none-eabi-objdump.exe

Working Directory (рабочая папка):
Нажмите Browse Workspace... и выберите ваш проект.

Arguments (аргументы командной строки):
Скопируйте туда эту строку:

text
-h "Debug/${project_name}.elf"
Где:

-h – тот самый параметр из вашего примера (показывает все секции).

Весь остальной путь – автоматически подставляет имя вашего проекта.

Шаг 4. Запустить
Нажмите Apply, затем Run.

В нижней части IDE откроется вкладка Console.
